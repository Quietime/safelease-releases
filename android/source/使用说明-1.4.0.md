# SafeLease SG 1.4.0

新增实际可操作的房源核查详情。入口：检查房源 → 打开一条预查 → 房源核查详情。申请者确认共享范围并选择本次出租标签和结束日期后提交。本地工作人员在人工复核页进入“房源核查队列”，领取申请，再填写人工观察、名册参考及方法说明。申请者不能自行审批，未领取的工作人员不能读取详情。

本页分别显示电话观察、工作人员记录和日期、未核查的产权/出租授权/房间状况/账户归属、仅限本次出租的有效范围，以及撤销、举报、回复和历史。到期或撤销后不能继续完成或复用。已记录的观察和出租范围不能覆盖改写。

这是本机人工记录流程，不是独立认证服务；不自动查询CEA、不证明真实身份或产权。样例截图的电话结果为无法判断，没有假设实际查询成功。照片和原始截图不向房源核查工作人员共享；仅共享申请者同意的标签、公开链接和电话。全部既有租约功能保留。

新增17项流程/权限检查、24项颜色与布局检查、11项原有核心流程回归通过。早期1.4.0候选安装包完成10项原生更新校验；最终包签名再核对通过。最后增加的空电话校验完成3项本地JS模块测试：无电话时不能记录匹配/未匹配，可记录无法判断。

自动审批拦截了最后一轮包含模拟器重装的补测命令，未给出更具体原因。最终空电话输入校验没有重做Android安装验证；图片和主要流程是在此前构建中实际运行取得，最后改动没有改变界面呈现。QA报告区分这两种验证范围。

清单已更新为1.4.0，13张图包含第7页的待审核、人工记录、已撤销三种状态。图片均来自真实App运行，使用本地样例而非真实房源认证。访客账户不会自动获得截图中的QA样例数据。

直接覆盖安装同包名旧版以保留本机记录，不要先卸载。旧版的访客、保存会话、相机、证据导出、自动更新及1秒开屏继续可用。
