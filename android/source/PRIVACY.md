# Privacy — local edition 1.0.0

SafeLease SG stores the rental details you enter, listing screenshots, in-app camera captures, notes and local activity in Android app-private storage. No account is created. No analytics, advertising, location collection or cloud upload service is included.

Camera permission is requested only when you open the in-app camera. You can deny it; the application explains how to enable it later. Screenshots can be selected through Android's document picker, without granting general storage access. Move-in evidence cannot be imported from the gallery.

Public reference data is bundled separately. It includes official professional-registration information, historical HDB rental approvals, factual rental-lead links and short source-linked summaries. A public directory entry is not a finding about the person contacting you. Sources, snapshot date, coverage and licences are shown in the app.

Opening CEA, Maps or any other external source launches your browser. That website has its own privacy practices. Sharing a message or saving an export requires an explicit action. Android handles the sharesheet, print/PDF destination and ZIP destination. Any copies you save or send are outside the app's storage and deletion controls.

The application does not request NRIC, FIN, passport numbers, bank credentials, payment access or location permission. Do not put unnecessary identity details into free-text notes or screenshots. A separately engaged property agent may have legal due-diligence obligations; this app does not replace that process.

Delete local data from Profile by typing DELETE in the confirmation dialog. Export first if you want a copy. Uninstalling removes the app's private records. Automatic cloud backups and device-transfer backups are disabled in the app configuration. Already exported files are not deleted by the app. No twelve-month automatic deletion service is provided or promised.

SHA-256 identifies the generated captured JPEG bytes. It does not independently establish the image's time, location or truth. Device times can change, no trusted server timestamp is collected, and C2PA is not inspected. The local record remains one-sided; no landlord confirmation is collected online.

## 中文说明

本机版将你填写的租约、房源截图、应用内拍摄的照片、备注与操作记录保存在安卓应用私有存储中。不创建在线账号，不包含分析、广告、定位收集或云端上传服务。

仅在打开应用相机时申请相机权限。你可以拒绝，之后按应用提示在安卓设置中开启。房源截图通过系统文件选择器选取，不申请整机存储访问权限；入住证据不接受从相册导入。

公开参考数据与私人记录分开存放。公开数据包括职业登记、历史组屋租赁批准、事实性房源链接及简短来源摘要，目录记录不能证明联系者的身份。应用会显示来源、快照日期、覆盖范围与许可信息。

打开 CEA、地图等外部链接会使用浏览器，相关网站适用自己的隐私规则。消息分享与文件保存均由你主动发起。安卓负责分享界面、PDF 保存位置和 ZIP 保存位置。你导出或发送的副本不受应用内删除操作控制。

应用不要求 NRIC、FIN、护照号码、银行凭据、付款权限或定位权限。请勿在自由备注或截图中加入不必要的证件资料。你另行委托的房产中介可能承担法定尽职调查义务，本应用不能替代该流程。

在个人中心输入 DELETE 后可删除本机私人记录，需要保留请先导出。卸载会移除应用私有记录，已导出文件不会被应用删除。应用配置禁用自动云备份及设备转移备份，不提供或承诺十二个月后自动删除服务。

SHA-256 只识别拍摄所得 JPEG 文件的字节，不独立证明照片时间、地点或真实性。设备时间可更改，应用不收集可信服务端时间戳，也未检查 C2PA。记录保持单方状态，未在线收集房东确认。
