# SafeLease SG 1.3.0

直接覆盖安装SafeLease-SG-1.3.0.apk，不要先卸载或清除存储。支持Android9及以上及较新的系统WebView。

访客登录和保持登录继续可用。登录后首页点击“检查房源”，粘贴公开HTTPS链接或上传本机PNG/JPEG截图，填写可选电话和地址，按实际情况勾选看房前付款，再开始检查。截图不作OCR或实时图片反查。按引导自行打开CEA名册并记录观察；不要将观察理解为认证。

创建租约时可填写租约上的业主姓名和房间清单。租约页提供核对收款人、押金跟踪、证据包和记录权限四个入口。拍照前核对房间名称；进度按该名称统计。原片只通过应用内相机拍摄，普通房源截图不会变成入住原片。

租约双方须分别登录并确认同一版本。已确认基线不允许直接覆盖，后续补充不继承确认。房东拒绝参与时显示单方记录。

在押金页填写拟续租结束日期可检查日期跨度；此项不会修改原合同日期或照片保留期限。正式续租请新建租约。退款登记只填实际收到的金额。

在证据包中完成信函、核对附件清单并保存，然后导出信函PDF或完整证据。完整PDF会附保存的信函草稿，完整ZIP另含信函PDF和全部保留原片。附件勾选不筛除完整证据包内容，发送前务必核对。信函由你自行发送，应用不代发、不转账，也不提供法律结论。

记录权限页显示实际权限和最近100条日志。系统按退租后12个月计算照片到期时间，在前台清理时移除到期原片；未结复核会保留原片。清除安卓存储或卸载仍会丢失本机数据，请保管私有导出。

自动更新、1秒开屏和原红白配色保留。设置中可手动检查更新。安卓仍需你确认安装；应用下载的私有更新包在安装成功后清理。手工保存在下载目录的首次安装包不属于该私有缓存。

暂不提供实时图片反查、截图OCR、平台Verified Listing认证或跨设备同步。内置观察、原始输入和照片不因语言切换而改写。真机相机及更新安装尚未作为本轮验收结论。


截图中的950元及拍照/确认状态是在QA中按实际流程准备的样例，不会自动导入新安装的访客账户。访客记录默认独立；可以按界面创建自己的租约和房间计划。旧账户的原样例与原记录在升级后保留。

另通过10项针对本次实际签名APK的原生更新校验及5项长房间名/中文320像素边界布局检查。QA中的脚本保留原工作区路径约定，验收报告可直接查看；脚本不是脱离原工作区依赖的一键测试程序。
